**Problem Statement:**

Using Java or Python develop these 3 applications:
1. Application to generate an RSA key pair, key size = 2048 bits (Standard Java library can be used to generate all keys and hashes).
2. Application to generate SHA-256 hash of the attached file. No signing is needed. Just print hash in HEX encoding to standard output.
3. Application that will encrypt and decrypt the file using the RSA key pair generated.
4. Send us public and private key, along with original and encrypted files so we can confirm the contents of the file is the same as the file encrypted.

**Code structure:**
1. The solution to Application 1 lives in RSAKeyGenerator.java
    - Generates a 2048-bit RSA public and private key pair using Java's KeyPairGenerator class.
2. The solution to Application 2 lives in SHA256Hasher.java
    - Reads a file, calculates its SHA-256 hash using Java's MessageDigest class, and prints the result in hexadecimal format to standard output.
    - The hash can be used to verify that the decrypted file matches the original.
3. The solution to Application 3 lives in RSAFileEncryptor.java
    - Encrypts and decrypts the image using the generated RSA key pair.
    - Since RSA-2048 with OAEP-SHA256 padding can encrypt a maximum of 190 bytes at a time, the image is processed in smaller chunks.

**Note:**
public.key and private.key contain the keys generated by Application 1

**Encryption:**

Reads CodingExercise.JPG as a byte array.
Splits the file into chunks of up to 190 bytes.
Encrypts each chunk using the RSA public key.
Combines the encrypted chunks and saves them to encrypted.bin.

**Decryption:**
Reads encrypted.bin.
Splits the encrypted data into 256-byte chunks.
Decrypts each chunk using the RSA private key.
Combines the decrypted chunks and saves them to decrypted.JPG.
Compares the decrypted bytes against the original file to verify that they match.

**Requirements:**
Java JDK 17 or newer
No external libraries required

**How to Run:**
Open a terminal in the project directory.

1. Compile the applications
javac RSAKeyGenerator.java SHA256Hasher.java RSAFileEncryptor.java

2. Generate the RSA key pair
java RSAKeyGenerator

3. Generate the SHA-256 hash
java SHA256Hasher CodingExercise.JPG

4. Encrypt and decrypt the image
java RSAFileEncryptor

This generates encrypted.bin and decrypted.JPG.
